# Außenposten – Downloads

Fertige Installationsdateien von **Außenposten**, einem Aufbau- und Verteidigungsspiel: automatische Fabrik auf einem fremden Planeten, nachts gegen Kreaturen verteidigen, am Ende mit der Rakete nach Hause.
Dieses Repository enthält **keinen Quellcode**, nur die veröffentlichten Versionen.

Am einfachsten installierst und aktualisierst du Außenposten über den [Appstore](https://github.com/Malwin1234/appstore-releases).

## Android

1. Unter [Releases](../../releases/latest) die Datei `Aussenposten-<Version>.apk` herunterladen und öffnen.
2. Android fragt einmal nach „Unbekannte Apps installieren“ für Browser bzw. Dateimanager.
3. Wer vorher eine Entwicklerversion hatte: diese zuerst deinstallieren (anderer Schlüssel). Den Spielstand vorher über ☁️ Geräte-Sync hochladen oder unter 💾 Spielstände als Code sichern.

## Windows

1. Unter [Releases](../../releases/latest) die Datei `Aussenposten-Setup-<Version>.exe` herunterladen und starten. Installation nur für den eigenen Benutzer, ohne Administratorrechte.
2. Die App ist nicht signiert. Windows zeigt deshalb beim ersten Start eine SmartScreen-Warnung: **Weitere Informationen → Trotzdem ausführen**.
3. Prüfsumme vergleichen (optional): `Get-FileHash Aussenposten-Setup-<Version>.exe` gegen die `.sha256`-Datei im Release.

## Spielstand auf mehreren Geräten

Im Spiel unter **Einstellungen → ☁️ Geräte-Sync** lässt sich der Spielstand über einen eigenen Sync-Server (Docker) zwischen Handy und PC abgleichen.
